# XERDNA

**Discover the Unknown Within Life.**

XERDNA is a Biological Intelligence Platform. Its mission is to organize humanity's biological knowledge, connect scientific evidence, and accelerate discovery through artificial intelligence — while never replacing laboratory validation.

It started as an AI primer design idea. The vision evolved into something much larger: infrastructure meant to serve biology for decades, not a single application.

## This Repository Is Governed by a Constitution

XERDNA is built architecture-first: **principles before architecture, architecture before implementation, science before software.** Four documents form its constitutional foundation. Nothing built in any phase — schema, database, ingestion, API, backend, or interface — is authoritative until it traces back to a ratified article in these documents.

## Status

**Phase 1 of the Roadmap — Universal Biological Memory (foundational stage).**

This repository contains ratified constitutional documentation and Phase 1 conceptual architecture (GRAPH/SCHEMA.md and its governance artifacts). No implementation — database, ingestion pipeline, API, backend, or frontend code — has been authorized yet.

## Guiding Principles

**"Build for 2,000 phases, not the next 20."**
The roadmap names phases today, but that count describes the current horizon, not a ceiling. Foundational components — the knowledge graph, the evidence model, provenance — are built to carry weight for decades, for people not yet in the room.

**"Scientific Constitution Before Code."**
No technical decision precedes the constitutional principle that authorizes it. If implementation work exposes a gap the constitution doesn't cover, the constitution is amended first (MASTER_CONTEXT.md Article III) — it is never quietly worked around.

## Scientific Integrity

XERDNA always distinguishes between:

- **Established Evidence** — validated, sourced, citable fact
- **Computational Prediction** — model or simulation output, not yet validated
- **Research Hypothesis** — a generated, evidence-ranked question for researchers to pursue

It never claims discoveries. It assists scientists — it does not replace laboratory validation. See [VISION.md](VISION.md) for the full reasoning, including the AI and Ethical Principles that bind every future phase.
